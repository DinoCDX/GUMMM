# Changelog

## 1.5
- Repository added to About
- Auto updater: checks the latest GitHub release and installs its APK
- Colored band on each mod: green active, yellow conflict, red error, grey off
- Mods load from bottom to top, the top mod wins
- Split APK games: installed apps with splits and .apks, .xapk, .apkm bundles
- Files tab: browse, search, view, export and edit the game files, and compare with the modded build
- App icon
- External mod folder is now the default on Android 11 or newer
- Clearer All files access prompt on the first external build
- Resource pack mods (.pck and .zip) with automatic type detection and a manual override
- Godot Mod Loader mods: bundled framework for Godot 4 games, and Godot 3 games that already include it such as Brotato (experimental)
- GitHub page
