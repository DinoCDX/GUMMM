GUMMM

A mobile port of GUMM. Add mods to Godot games on Android, no PC needed.

Download APK Source on GitHub

Screenshots

What it does

  • Pick an installed Godot 3 or 4 game, or an APK file.
  • Import mod zips or folders (a mod needs mod.cfg and mod.gd).
  • Switch mods on and off, reorder them, see conflicts.
  • Builds a patched APK, signs it and installs it next to the original game.
  • Optional in-game button to switch mods while playing.
  • Checks GitHub for new releases and updates itself.

Mod status

ActiveEnabled and ready to load
ConflictReplaces the same file as another mod
ErrorMissing script or failed to load
Not activeSwitched off

Mods load from bottom to top, so the mod at the top wins a conflict.

Install

  • Download the APK from the latest release.
  • Allow installs from your browser or file manager when Android asks.
  • Open GUMMM, tap add, and choose your game.
  • Import mods in the Mods tab, then build and install.

Making a mod

A mod is a folder or zip with a mod.cfg and a mod.gd. A zip with several mods imports them all.

mod.cfg

name = "My Mod"
version = "1.0"
author = "You"
description = "What it changes"

mod.gd

extends Node

func initialize(mod_path, scene_tree):
    print("loaded from ", mod_path)

The loader calls initialize(mod_path, scene_tree), or _initialize(scene_tree) if that is what the mod has. An optional icon.png is shown next to the mod. Add set_enabled(bool) to let the in-game button switch the mod live.

Updates

GUMMM checks the latest GitHub release on start. If a newer version exists it offers to download and install it. You can switch this off or check by hand in App settings, About.

First build

With external mods, Android asks for All files access twice, once for GUMMM and once for the modded game. GUMMM explains this and takes you to the right settings page. You only do it once.

Notes

  • Android 9 or newer.
  • Mods load from an external folder by default on Android 11 or newer, which needs All files access. Packed mode is available in settings.
  • Copying save data needs root.
  • Split APK games are not supported yet.
